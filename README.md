# Large Language Models for Public Opinion Research: A Practical Guide

Code and data companion repository for:

> Kennedy, R., Shor, B., & Austin, A. (forthcoming). *Large Language Models
> for Public Opinion Research: A Practical Guide*. Cambridge University Press
> Elements.

## Authors

- **Ryan Kennedy** — Ohio State University
- **Boris Shor** — University of Houston
- **Amanda Austin** — University of Houston

## Repository Structure

```
chapter-01/
  Code/       R scripts for Chapter 1 (foundations, APIs, prompting)
chapter-02/
  Code/       R scripts for Chapter 2 (silicon sampling)
  Data/       Input data (CCES 2021 subset)
  Plots/      Figures generated by the chapter-02 scripts
  Tables/     Summary tables generated by the chapter-02 scripts
chapter-03/
  Code/       R scripts for Chapter 3 plus smithforcitycouncil.md
              for the Shiny tool example
```

### Chapter 1 — LLMs: Foundations

Covers the transformer architecture, interacting with LLMs via the OpenAI
API, the `ellmer` R package, prompt engineering (C.R.E.A.T.E. framework),
and controlling output parameters such as temperature.

### Chapter 2 — Silicon Sampling

Demonstrates using LLMs to generate synthetic survey responses from
demographic profiles, then validates the results against real CCES data.
Scripts are numbered sequentially (01–11); run them in order.
The `Possible/` subfolder contains experimental extensions.

### Chapter 3 — AI Interviewing

Walks through building an AI interviewer in R: a single-agent prompted
interviewer, a multi-agent variant with an answer-checking agent, and a
full Shiny application that combines tool use (retrieval from a campaign
document) with a survey interviewing flow. `app.R` is the complete
runnable Shiny app; the book displays it in pieces. Run the app from the
`chapter-03/Code/` folder so it can read `smithforcitycouncil.md` by filename.

## API Keys

Chapter 1 and Chapter 2 cloud examples use the OpenAI API (default model:
`gpt-5.4-mini`). Chapter 3 uses `gpt-5.4`. Obtain a key at
<https://platform.openai.com> and store it in your project `.Renviron`:

```
OPENAI_API_KEY=<your key here>
```

Chapter 2 also includes a local-model example (`03c - Local model.R`) using
[Ollama](https://ollama.com), which requires no API key.

## Data

`chapter-02/Data/` contains a subset of the 2021 Cooperative Congressional
Election Study (CCES). See the
[CCES homepage](https://cces.gov.harvard.edu) for full data and codebook.
